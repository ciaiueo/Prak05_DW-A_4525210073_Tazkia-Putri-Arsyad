# LUNÉA — Online Women's Shop

## 1. Deskripsi Proyek

LUNÉA merupakan rancangan website toko pakaian wanita yang menampilkan koleksi pakaian hijab dan casual. Website ini dibuat menggunakan HTML5 dan CSS3 dengan tampilan feminin yang memadukan warna cream, dusty pink, dan cokelat.

Website ini dirancang agar pengunjung dapat melihat informasi toko, kategori pakaian, daftar produk, serta harga produk dengan tampilan yang rapi dan mudah dipahami.

## 2. Tujuan

Tujuan pembuatan website LUNÉA adalah untuk menerapkan penggunaan HTML dan CSS dalam membangun halaman web, mengatur tata letak menggunakan Flexbox dan Grid, serta membuat tampilan yang responsif pada perangkat desktop dan mobile.

## 3. Teknologi yang Digunakan

- **HTML5:** Membuat struktur dan konten halaman website.
- **CSS3:** Mengatur warna, tipografi, tata letak, gambar, dan tampilan responsif.
- **Visual Studio Code:** Digunakan untuk menulis dan mengedit kode program.
- **Browser:** Digunakan untuk melihat dan menguji hasil website.

## 4. Fitur dan Bagian Website

1. **Header dan Navigasi** — Menampilkan logo LUNÉA dan menu navigasi.
2. **Hero Section** — Menampilkan pengenalan toko dan gambar utama.
3. **Kategori Produk** — Menampilkan kategori Hijab Set, Casual Set, dan Daily Outfit.
4. **Daftar Produk** — Menampilkan gambar, nama, dan harga beberapa produk.
5. **Tentang LUNÉA** — Memberikan informasi singkat mengenai toko.
6. **Footer** — Menampilkan bagian penutup halaman website.

Website ini merupakan website statis untuk menampilkan informasi dan katalog produk. Fitur transaksi dan pembayaran belum diterapkan.

## 6. Cara Menjalankan Website

1. Buka folder `LUNEA-Online-Shop` menggunakan Visual Studio Code.
2. Pastikan file `index.html`, `css/style.css`, dan gambar pada folder `images` tersedia.
3. Buka file `index.html` melalui browser, atau gunakan ekstensi Live Server jika tersedia.
4. Periksa tampilan website dan navigasi pada browser.
5. Uji tampilan pada ukuran desktop dan mobile menggunakan fitur Device Toolbar di browser.

## 8. Ringkasan Praktikum

Pada praktikum ini, saya membuat website LUNÉA sebagai rancangan toko pakaian wanita menggunakan HTML5 dan CSS3. Website memiliki beberapa bagian, yaitu header, navigasi, hero section, kategori produk, daftar produk, informasi toko, dan footer. Saya menggunakan HTML untuk menyusun struktur halaman, sedangkan CSS digunakan untuk mengatur warna, ukuran teks, jarak, gambar, dan tata letak.

Tantangan dalam pengerjaan website ini adalah mengatur susunan elemen agar terlihat rapi serta menyesuaikan tampilan pada ukuran layar yang berbeda. Untuk mengatasinya, saya menggunakan Flexbox, Grid, dan media query agar elemen website dapat menyesuaikan ukuran layar desktop maupun mobile. Saya juga mengatur gambar menggunakan CSS supaya tampil sesuai dengan ukuran area yang tersedia.

Melalui praktikum ini, saya memahami bahwa pembuatan website tidak hanya memperhatikan tampilan pada desktop, tetapi juga perlu mempertimbangkan kenyamanan pengguna pada perangkat mobile. Saya juga belajar menyusun file HTML, CSS, gambar, dan dokumentasi dalam folder yang terstruktur agar proyek lebih mudah dibuka dan dikembangkan kembali.
